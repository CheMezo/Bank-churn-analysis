# Bank-churn-analysis

**About the Project**
This project analyzes bank customer churn to identify customer segments with higher churn rates and understand how customer balance is distributed among churned customers.

**Objectives**
- Analyze the overall customer churn pattern.
- Identify geographical segments with higher churn rates.
- Examine the balance distribution of churned customers.
- Provide insights to support customer retention strategies.

**Tools that I used**
- Microsoft Excel for data cleaning and data standardization
- MySQL for EDA and answering business question
- Power BI for Visualization
